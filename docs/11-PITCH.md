# Pitch

## One-liner
**Quorum is the collaborative decision stack for AI-native product teams.**

## Opening frame
AI has made building dramatically faster. PMs prototype in code, designers increasingly work in code, and engineers build with agents. As implementation gets cheaper, the bottleneck moves from coding to **decision-making**.

## Problem
Today, the context behind product decisions is fragmented across:
- preview comments
- Slack
- analytics dashboards
- product docs
- requirements
- meetings
- private AI chats

This makes it hard for teams to answer:
- why does this exist?
- is this aligned with our design process?
- what evidence do we have?
- who decided this?
- what exactly should the coding agent implement?

## Solution
Quorum turns the running product into a shared decision surface.

On any live prototype or preview, the team can:
1. select an element or draw over a region
2. start a shared thread
3. ask the agent for grounded context
4. tag teammates when human knowledge is needed
5. validate with process, precedent, and external evidence
6. convert the discussion into action items

## Why it matters
Quorum reduces context loss and creates better implementation-ready decisions for teams and coding agents.

## Demo promise
In the demo, Quorum will show:
- multiplayer review in a live product
- grounded answers from local context
- a real Context.dev fetch
- realtime Convex-backed collaboration
- action synthesis from discussion
- a lightweight workspace where everything persists
