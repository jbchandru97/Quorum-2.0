# Usability review process

Every new interaction is assessed against five criteria before it ships.

## 1. Discoverability
Can the user find it at the moment it is useful, without being told?

## 2. Clarity and transparency
Before acting, does the user know what will happen and what will be used?
An AI affordance must say what it will look at, not only what it will do.

## 3. Cognitive load
Does it add a decision at a point where the user was already deciding
something else?

## 4. Consistency with existing patterns
Does it behave like its siblings elsewhere in the product?

## 5. User control
Can the user decline, undo, or leave without losing their place?

## Recording an assessment

Each criterion gets **Pass**, **Needs review**, or **Fail**, with one line of
evidence. A criterion with no evidence available is recorded as unassessed —
not as a pass.
